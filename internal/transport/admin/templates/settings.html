Bot protection (Cloudflare Turnstile)

Require the Turnstile check

Your app shows the Turnstile widget and sends its token with the request. Warden checks the token with Cloudflare on the server, using the secret key, together with the hostname and the action. If Cloudflare cannot be reached, the request is refused. Create a widget at dash.cloudflare.com → Turnstile.

Public. Apps read it from GET /v1/auth/providers to render the widget.

Stays on the server and is stored encrypted. It is never shown again.

Security notifications

Sign-in from a new device

Email the user the first time their account signs in from a browser or app it has not used in 180 days: device, IP, country (behind Cloudflare or a similar proxy), method and time, with a button that ends that session. A new account's first device never triggers it. At most 3 per account per hour.

Account locked

Email the user once when wrong passwords reach the lockout threshold, so they learn someone is guessing.

Password and two-factor changes are always notified.
