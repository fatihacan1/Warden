What your endpoint receives

POST /webhooks/warden HTTP/1.1
Content-Type: application/json
webhook-id: 01929b7e-5f0c-7d3a-9c1e-6a0d1b2c3d4e
webhook-timestamp: 1761127200
webhook-signature: v1,K5oZfzN95Z9UVu1EsfQmfVNQhnkZ2pj9o9NDN/H/pI4=

{
  "id": "01929b7e-5f0c-7d3a-9c1e-6a0d1b2c3d4e",
  "type": "user.created",
  "occurred_at": "2026-10-22T10:00:00Z",
  "user_id": "01929b7e-1111-7aaa-8bbb-0123456789ab",
  "data": { "email": "ada@example.com", "method": "password" }
}
  1. Verify the signature with your endpoint's secret before trusting the body. It follows Standard Webhooks, so libraries exist for every language; the Warden SDK has verifyWebhook().
  2. Reject timestamps older than 5 minutes (replays) and answer 2xx quickly; do slow work in the background.
  3. Deliveries are at-least-once. Deduplicate on id, which is also the RabbitMQ message id of the same event.
  4. Answer 410 Gone to stop receiving an event permanently. Any other non-2xx answer is retried with backoff.
